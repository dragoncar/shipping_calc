# 运费计算器 v1.0

一个离线可用的 PWA 运费计算工具，输入重量和地址即可自动计算运费。

## 功能

- **重量输入**：支持小数、中文逗号，附带快捷键（1/3/5/10/20kg，可自定义）
- **地址识别**：支持输入完整地址自动识别省份，也支持输入城市名/县名自动匹配
- **智能计价**：特殊地区价、常规阶梯价（≤12kg / 13-15 / 16-20 / 21-89 / ≥90）
- **不发快递提示**：新疆/西藏地区自动提示不发货
- **重置/复制**：一键清空、一键复制运费明细到微信
- **离线可用**：首次打开后支持离线使用（PWA）
- **数据持久化**：快捷键自定义设置自动保存

## 地址识别覆盖

基于国家官方行政区划数据，支持识别 **全国 6264 个** 地级市、县级市、县、区、旗。

## 使用

直接在浏览器打开 `index.html` 即可使用。  
推荐添加到主屏幕（iOS Safari：分享 → 添加到主屏幕）获得离线能力。
